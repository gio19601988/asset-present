ბაზისური პაკეტის დანერგვა 2–3 სამუშაო დღეში ხდება: ინსტალაცია, მონაცემების იმპორტი Excel-იდან და გუნდის საბაზისო ტრენინგი. ენტერპრაიზ ვერსია ინდივიდუალური გეგმით ინერგება — მოდულების რაოდენობისა და ინტეგრაციების მიხედვით.
სისტემა მხოლოდ სამედიცინო ორგანიზაციებისთვისაა?
არა. აქტივების, ფინანსების, საწყობის, შეკვეთების, HR-ის, დოკუმენტების და CRM-ის მოდულები ნებისმიერი ორგანიზაციისთვისაა. სამედიცინო მოდულები დამატებითია და ირთვება მხოლოდ საჭიროების შემთხვევაში.
შეიძლება მხოლოდ საჭირო მოდულების ჩართვა?
დიახ. მოდულები ირთვება და ითიშება მონაცემების წაშლის გარეშე. გამორთული მოდულის API დახურულია, ბირთვი კი გამორთვისგან დაცულია — უკან ჩართვის გზა ყოველთვის რჩება.
როგორ მუშაობს ORIS 5-თან ინტეგრაცია?
სისტემა ORIS 5-დან კითხულობს ბუღალტრულ ნაშთებს, გატარებებს და მომწოდებლებს და ინახავს სნეპშოტებად — განრიგით ან ხელით განახლებით. ძვირი აგრეგაცია ერთხელ ითვლება, ამიტომ რეპორტები 80–500 მილიწამში იხსნება. ხელით შეტანილი შესწორებები სინქრონიზაციისას არ გადაიწერება.
შესაძლებელია არსებული მონაცემების გადმოტანა?
დიახ. სისტემა მხარს უჭერს მასობრივ იმპორტს Excel-იდან (შაბლონით, ავტო-ვალიდაციით და დუბლიკატების შემოწმებით) და PDF ზედდებულიდან. ჩვენ დაგეხმარებით მონაცემების სწორად სტრუქტურირებაში.
ინტერნეტი საჭიროა სისტემის მუშაობისთვის?
არა. AssetFlow Studio ეშვება თქვენს ლოკალურ სერვერზე (on-premise) და სრულად ფუნქციონირებს შიდა ქსელში. ინტერნეტი სჭირდება მხოლოდ გარე სერვისებს — მაგალითად, ეროვნული ბანკის კურსებს; კავშირის გარეშე სისტემა ბოლო ცნობილ კურსს იყენებს.
რა ტექნიკური მოთხოვნებია?
სერვერი: Windows Server (ან Linux) + SQL Server 2019+, .NET 8. კლიენტი: ნებისმიერი თანამედროვე ბრაუზერი (Chrome, Edge, Firefox, Safari). კლიენტის მხარეს ინსტალაცია არ არის საჭირო.
რა ენებზეა ხელმისაწვდომი?
ქართულად და ინგლისურად. თარგმანები ინახება ბაზაში და რედაქტირდება პროგრამისტის გარეშე; ახალი ენის დამატება ცხრილში ერთი ჩანაწერია.
რამდენ მომხმარებელს შეუძლია ერთდროულად მუშაობა?
სტარტერი — 3 მომხმარებელი, პროფესიონალი — 10, ენტერპრაიზი — შეუზღუდავი. თითოეულ მომხმარებელს RBAC-ით განსაზღვრული ინდივიდუალური უფლებები აქვს.
რა ხდება საცდელი პერიოდის შემდეგ?
14-დღიანი საცდელი პერიოდი სრულიად უფასოა და ყველა ფუნქცია ხელმისაწვდომია. შემდეგ ირჩევთ შესაფერის გეგმას; თუ სისტემა არ მოგეწონათ — არანაირი ვალდებულება.

In August–September 2026 the platform went through a full security hardening.

Access

  • Uploaded files require authorization too

Secrets

  • No passwords in code or Git

  • Corrections only via a new record

FAQ

Frequently asked questions

How long does implementation take?
The core package is typically up and running in 2–3 business days: installation, Excel data import and basic team training. Enterprise deployments follow an individual plan based on the number of modules and integrations.
Is it only for healthcare organizations?
No. The asset, finance, warehouse, purchasing, HR, document and CRM modules work for any organization. Healthcare modules are optional and enabled only when needed.
Can I enable only the modules I need?
Yes. Modules can be switched on and off without deleting data. A disabled module's API is closed, the core is protected from being disabled, and you can always switch a module back on.
How does the ORIS 5 integration work?
AssetFlow Studio reads balances, entries and suppliers from ORIS 5 and stores them as snapshots, refreshed on a schedule or on demand. Heavy aggregation is computed once, so reports open in 80–500 ms. Manual corrections are preserved on every sync.
Can we migrate our existing data?
Yes. Bulk import from Excel (template-based, with automatic validation and duplicate checks) and from PDF invoices is built in, and we help you structure your data correctly.
Does it need an internet connection?
No. AssetFlow Studio runs on your own servers (on-premise) and works fully inside your local network. Internet access is only used by external services such as National Bank exchange rates; when offline, the last known rate is used.
What are the technical requirements?
Server: Windows Server (or Linux) with SQL Server 2019+ and .NET 8. Client: any modern browser (Chrome, Edge, Firefox, Safari). Nothing needs to be installed on user machines.
Which languages are supported?
English and Georgian. Translations are stored in the database and can be edited without a developer; adding a new language is a single table row.
How many users can work at the same time?
Starter — 3 users, Professional — 10, Enterprise — unlimited. Every user has individual permissions defined by RBAC.
What happens after the trial?
The 14-day trial is completely free with every feature available. Afterwards you choose the plan that fits; if it's not right for you, there's no obligation.
